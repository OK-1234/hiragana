# ゆびで！ビーム

幼稚園児向けの、指の動きから文字を書く体験へ進むブラウザゲームです。既存の7つの準備ステージを遊んだ後、「し」「く」の文字バトルへ進めます。読み上げ問題・オンライン機能はありません。

## 起動と操作

`index.html` をブラウザで開くだけで動きます（ネット接続・インストール不要）。ローカルプレビューは `npm start` → http://localhost:4173 。スマートフォン・iPadで試す場合は、同じWi-Fi上でPCのIPアドレスの4173番ポートへアクセスします。端末からのアクセスにはPCのファイアウォール設定が影響する場合があります。

光る紫の星をタップ。2つめからは星に触れたまま、白い道の終わりまで指を動かします。マウスではドラッグします。成功するとすぐにビーム・敵リアクション・応援コメントが発生し、次へ進みます。7つ終えると敵と仲よくなり、「もじの ほしへ」で文字バトルへ進めます。「もういっかい」で準備ステージだけを再プレイすることもできます。音は初期OFF、右上のボタンで短い合成効果音をONにできます。

1. 光る開始点をタップ
2. 短い直線
3. 長い直線
4. 途中で曲がる線
5. ゆるいカーブ
6. 大きなカーブ
7. 直線とカーブの組み合わせ

## 文字のバトル

対象は「し」「く」。準備ステージのカーブと方向転換につなげるための選択であり、科学的な難易度ランキングではありません。「つ」は選択肢だけに登場します。

| 段階 | ゲーム内の体験 |
| --- | --- |
| 見る | 敵のバリアに大きな弱点の形が出現し、筆順に沿って光が動く。約2.4秒で次へ。タップで先へ進むことも可能 |
| 選ぶ | 3つの大きな形から弱点を選んでバリアを攻撃。異なる形はバリアにはじかれ、約0.5秒で再挑戦 |
| なぞる | 大きな開始点と光のガイドを追い、エネルギーをためてビーム |
| 見ながら書く | 書字領域の上に小さな見本を表示。白紙に指で描き、離すと強攻撃の判定 |
| 見本を消して書く | 約1.9秒見本を見せてから消す。白紙に描いて指を離すと必殺技の判定。三重ビームと大きな光で敵撃破 |

各文字の撃破後に次の文字へ進みます。2文字のあとに文字バトルを再プレイできます。下部の「はじめの ほしへ」でいつでも準備ステージへ戻れます。

### 書字判定とヒント

なぞりは順番付きの経路判定で、SVG座標で33の幅を許容します。大きく外れても約0.42秒は戻せます。自由書字はこの判定を使わず、指を離してから「開始位置の広い領域」「初動の方向」「順番に通過した5つの広い領域」「終点付近」「線の長さ」を確認します。線の震えや小さな位置ずれを許容し、点だけ・逆向き・極端な近道・長すぎる塗りつぶしは再挑戦になります。厳密な文字認識でも習得診断でもありません。

自由書字の書字領域には、最初から文字の経路を表示しません。約2.8秒動かなければ開始点が点滅し、約5.8秒で最初の方向だけを光が案内します。見本なしの段階は約9.5秒後から見本を約1.6秒だけ再表示し、また消します。なぞりの光ガイドは常時表示します。見本表示中の時間は、ページを別タブに切り替えている間は進みません。

軌道から外れるとエネルギーが消え、バリアが光ります。約0.4秒後には同じ操作に再挑戦できます。ゲームオーバー・点数・否定的な表示はありません。途中で指が止まっても終了しません。約2秒動きがないと、軌道上の光が進む方向を案内します。指を離した場合は開始点から再挑戦します。画面上のチャットは全て架空で、通信しません。

## 操作記録

下部の「保護者・開発用」、ブラウザコンソール、または `window.fingerBeamDebug.getRecords()` で確認できます。JSONのダウンロードも可能です。記録はメモリ上だけで保持され、リロードで消えます。

- ステージ表示、開始点以外へのタッチ、開始点へのタッチ
- 試行回数、攻撃成功、成功までの所要時間
- 軌道離脱／途中で指を離した／Pointerキャンセルなどの中断理由と到達率
- 指が約1.8秒止まった場所、ヒント表示、全ステージ完了
- 周回番号（再プレイしても記録を区別できます）
- 文字ごとの段階、見るの完了、選んだ候補、成功までの試行回数・再挑戦数
- 文字バトルで使ったヒント段階、停止開始と再開までの時間、書字の簡易判定結果、敵撃破

文字バトルの記録には `route: "letters"` と `character` が付き、同じデバッグ表示・JSON出力に含まれます。`window.fingerBeamDebug.getLetterState()` では進行状況を確認できます。生の書字軌跡は描画・判定中だけ保持し、出力する記録には含めません。

開始点を触った時点を1試行として数えます。開始点以外のタッチは別イベントで、試行数には含めません。記録は操作の観察用であり、能力・発達の診断ではありません。

## 構成と拡張

- `core.js`：ステージ定義・軌道生成・順序を確認する進行判定。判定幅はSVG座標で30、開始点の受付半径は37。終点への飛び越しと角の大幅な省略を防ぎ、小さな逆戻りは許容します。
- `game.js`：Pointer Events、状態遷移、ヒント、演出、架空チャット、記録、短いWeb Audio効果音。
- `letters.js`：文字データ、5段階の状態遷移、自由書字判定、段階的ヒント。文字追加はこのデータを起点に行えます（今回は一筆の文字のみ対応）。
- `letter-ui.js`：既存の敵・チャット・効果音を使う文字バトル画面とPointer Events。
- `style.css` / `index.html`：縦画面を優先するレスポンシブ画面、SVGキャラクター。外部フォントや画像は使用しません。
- `core.test.js` / `game.test.js`：経路の完走、終点への飛び越し、判定の許容幅、方向転換の省略、イベントハンドラによる7段階の完走・再挑戦・停止ヒント・キャンセルなどの回帰確認。`npm test`。イベントテストはDOMと時計を模した環境で行います。

`letters.test.js` と `letter-ui.test.js` は2文字の順次進行、自由書字、見本消去、ヒント、再挑戦、Pointerキャンセル、準備ステージとの接続を確認します。イベントテストはDOMと時計を模した環境です。

将来は文字データを増やし、記録を参照する次の文字の選択を追加できます。音だけ聞いて書く問題、録音、AI文字認識、永続保存、学習評価は未実装です。

実際の子どものプレイを観察して、開始点の大きさ・軌道の長さ・許容幅・進む速さを調整してください。特に小さい画面での操作感は実機での確認が必要です。

## 公開・開発時の注意

- `server.js` は同じWi-Fi上のスマートフォンから動作確認するため、全IPv4インターフェースで待ち受けます。配信対象はゲーム用6ファイルに限定していますが、認証やTLSを備えた公開運用用サーバーではありません。信頼できるネットワークでのみ起動し、インターネットへポート転送しないでください。
- デバッグ表示とコンソール出力は、要求仕様にある操作確認用です。自動送信・永続保存はありません。手動で書き出したプレイ記録を公開しないよう、`.gitignore` で除外しています。
- `.gitignore` は秘密情報やローカル設定・ログを含むファイルの誤追加を防ぐ補助です。無視対象でも強制追加は可能であり、既存のコミットから情報を削除するものではありません。公開対象は別途確認してください。
- `npm test` はゲームの既存テストに加え、`server.test.js` で不正URLへの400応答、配信ファイルの一致、配信対象外ファイルを取得できないことを確認します。ビルド工程はありません。
